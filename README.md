# CODSOFT-Internship

## Overview
This repository contains three programming projects developed as part of my internship. These projects demonstrate basic programming concepts, logical thinking, problem-solving, and object-oriented programming.

## Tasks Included

### Task 1: Number Guessing Game
A simple interactive game in which the computer generates a random number and the user tries to guess it.

**Features:**
- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Provides hints if the guess is too high or too low.
- Repeats until the correct number is guessed.
- Can limit the number of attempts.
- Supports multiple rounds and score tracking.

**Concepts Used:** Random number generation, loops, conditional statements, and user input.

### Task 2: Student Grade Calculator
A program that calculates a student's total marks, average percentage, and grade based on marks obtained in different subjects.

**Features:**
- Accepts marks out of 100 for each subject.
- Calculates total marks.
- Calculates average percentage.
- Assigns a grade based on the average.
- Displays the total marks, percentage, and final grade.
- Validates marks entered by the user.

**Concepts Used:** Arithmetic operations, variables, conditional statements, loops, and input validation.

**Example Grading Criteria:**
| Percentage Range | Grade |
|:----------------:|:-----:|
| 90% - 100%       | A+    |
| 80% - 89%        | A     |
| 70% - 79%        | B     |
| 60% - 69%        | C     |
| 50% - 59%        | D     |
| Below 50%        | F     |

*Note: The grading criteria can be modified according to the requirements.*

### Task 3: ATM Interface
A basic ATM simulation that allows users to perform simple banking operations through a menu-driven interface.

**Features:**
- Check account balance.
- Deposit money.
- Withdraw money.
- Validate transaction amounts.
- Prevent withdrawals when the balance is insufficient.
- Display transaction success or failure messages.
- Update the account balance after transactions.

**Main Components:**
- **ATM Class:** Handles user interaction and ATM operations.
- **Bank Account Class:** Stores the account balance and manages deposits and withdrawals.

**Concepts Used:** Object-oriented programming, classes, objects, methods, encapsulation, loops, and input validation.

*Note: This project is for educational purposes and is not connected to a real banking system.*
